# T06: Image gallery

Demonstrates three attributed, repository-hosted images with alt text and a
responsive layout.

```shell
uv run python teams_adaptive_cards/06_image_gallery/teams.py
uv run python teams_adaptive_cards/06_image_gallery/teams.py --send
```

Live delivery requires `EXAMPLE_ASSET_BASE_URL`. Image provenance and licenses
are documented in [`../assets/ATTRIBUTION.md`](../assets/ATTRIBUTION.md).
