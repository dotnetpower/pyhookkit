# Client capture gallery

This directory accepts actual Slack and Microsoft Teams client captures only.
No client captures are currently committed.

Use these filenames:

- `deployment-result-slack.png`
- `deployment-result-teams.png`
- `incident-alert-acknowledgment-slack.png`
- `incident-alert-acknowledgment-teams.png`
- `approval-request-slack.png`
- `approval-request-teams.png`
- `maintenance-notice-slack.png`
- `maintenance-notice-teams.png`

Crop captures to the message card and remove account, tenant, Team, channel, and
destination details before committing. Do not substitute generated HTML,
Adaptive Card Designer output, or other synthetic previews for client captures.
