# T02: Hero image

Demonstrates a full-width public HTTPS image, meaningful alt text, caption, and
fallback content.

```shell
uv run python teams_adaptive_cards/02_hero_image/teams.py
uv run python teams_adaptive_cards/02_hero_image/teams.py --send
```

Live delivery requires `EXAMPLE_ASSET_BASE_URL`; provider delivery success does
not prove that Teams fetched the image.
