# 통합 시나리오 캡처

[English](README.md)

이 파일들은 일회용 Bookinfo 스테이징 시나리오에서 가져온 실제 클라이언트
및 제어 플레인 캡처입니다.

| 파일 | 증거 자료 |
|---|---|
| `azure-aks-resources.png` | AKS 예제와 연결된 Azure 리소스 |
| `bookinfo-productpage.png` | Bookinfo 워크로드 응답 |
| `argocd-bookinfo-application.png` | Argo CD `Healthy` 및 `Synced` 애플리케이션 |
| `github-approval-pending.png` | GitHub Environment 승인 게이트 |
| `github-approval-complete.png` | 승인되고 완료된 릴리스 워크플로 |
| `gitlab-promotion-pipeline.png` | GitOps 검증 및 승격 |
| `gitlab-argocd-notification-pipeline.png` | Argo가 트리거한 알림 파이프라인 |
| `gitlab-incident-pipeline.png` | 인시던트 알림 파이프라인 |
| `gitlab-maintenance-pipeline.png` | 예정된 유지 관리 알림 |

캡처는 계정, 테넌트, 구독, 연결, 콜백 URL, Team, 채널 및 기타 환경별 ID
세부 정보를 제거하도록 잘라냈습니다. 민감 정보가 제거된 이미지를 자르지 않은
원본으로 대체하지 마세요.
