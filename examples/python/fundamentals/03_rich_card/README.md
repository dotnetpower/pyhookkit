# F03: Rich card

Adds ordered facts and context to Slack Block Kit and a polished Teams Adaptive
Card. Teams uses an image-led editorial header, a centered semantic severity
label, a two-column fact panel, and compact source/timestamp context. The hero
label sits on a theme-aware solid overlay so it remains readable over mixed
light and dark photography.

Both provider examples show the same presentation hero. Slack renders it as a
Block Kit image with required alt text, while Teams uses it as a decorative
Adaptive Card background. Live delivery resolves the shared synthetic asset
marker through `EXAMPLE_ASSET_BASE_URL`.
