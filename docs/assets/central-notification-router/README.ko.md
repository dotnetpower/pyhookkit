# 중앙 알림 라우터 캡처

[English](README.md)

이 캡처는 선택적 SQLite 라우터의 관리 환경을 설명합니다.

| 파일 | 용도 |
|---|---|
| `admin-dashboard.png` | 표준·비공개 Teams 대상, 최근 전송 상태, 인바운드 통합 및 민감 정보가 제거된 API 키 메타데이터를 합성 데이터로 보여 주는 관리 대시보드 |

모든 이름, 식별자, 경로, 타임스탬프 및 상태는 합성 값입니다. 캡처에는 관리자
토큰, 생산자 API 키, Teams 채널 링크 또는 공급자 자격 증명이 포함되지
않습니다.
