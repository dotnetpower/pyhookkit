# Provider-native inbound test vectors

These synthetic fixtures freeze provider payload-to-canonical transformations.
Authentication headers and secrets are generated by tests and are not stored in
fixtures.

| Provider | Input | Expected output |
|---|---|---|
| GitHub | `github/workflow-run.json` | `github/workflow-run.expected.json` |
| GitLab | `gitlab/pipeline.json` | `gitlab/pipeline.expected.json` |
| Azure DevOps | `azure-devops/build-complete.json` | `azure-devops/build-complete.expected.json` |

Argo CD is not listed because its Notifications template emits canonical JSON
directly rather than sending a provider-native payload.
