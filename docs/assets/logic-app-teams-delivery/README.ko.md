# Azure Logic App Teams 배달 캡처

[English](README.md)

민감 정보가 제거된 이 캡처는
[Azure Logic App Teams 배달 가이드](../../logic-app-teams-delivery.ko.md)와
함께 제공됩니다.

| 파일 | 증거 자료 |
|---|---|
| `logic-app-workflow-expanded.png` | HTTP 트리거, 검증 분기, Teams 동작 및 명시적 응답 |
| `logic-app-trigger-security.png` | 보안 트리거 입력 및 출력 활성화 |
| `logic-app-teams-action.png` | 동적 Team, 채널 및 Adaptive Card 구성 |
| `logic-app-run-history.png` | 성공한 라우팅 알림 실행 |
| `logic-app-run-success.png` | 성공한 트리거, 검증, Teams 게시 및 `201` 응답 경로 |

캡처는 Logic Apps 디자이너 프레임에 맞게 잘라냈습니다. 계정, 테넌트, 구독,
콜백 URL, 연결 ID, Team ID, 채널 ID, 실행 ID 및 메시지 ID 값은 제외되어
있습니다. 자르지 않은 원본으로 대체하지 마세요.
