Teams 채널 추가

링크에서 채널명을 추출하고 게시 계정의 Team 멤버십을 확인합니다. 비공개 채널은 채널 멤버십도 자동으로 추가합니다.

대상 ID도 이 채널명으로 만들며, 중복되면 -2, -3을 붙입니다.
같은 알림 경로를 지정한 채널들이 하나의 알림을 함께 받습니다.

인바운드 통합 추가

공급자 원본 Webhook을 인증하고 고정 경로나 채널로 변환합니다. 비밀 값은 환경 변수에 별도로 저장합니다.

GitHub는 Webhook secret, GitLab은 whsec_ signing token, Azure DevOps는 Basic 인증 password를 지정한 환경 변수에서 읽습니다.
