# Power Automate Teams 워크플로 캡처

[English](README.md)

민감 정보가 제거된 이 캡처는
[Power Automate Teams 워크플로 가이드](../../power-automate-teams-workflow.ko.md)와
함께 제공됩니다.

| 파일 | 증거 자료 |
|---|---|
| `create-service-account.png` | Microsoft 365 관리 센터에서 Teams 알림 서비스 계정의 기본 정보 입력 |
| `shared-flow-overview.png` | Teams Webhook 요청 트리거와 채널 카드 게시 작업으로 구성한 공통 흐름 |
| `team-member.png` | 서비스 계정을 추가하기 전 대상 Team의 빈 멤버 목록 |
| `team-member2.png` | 서비스 계정을 추가한 후 **Member** 역할 확인 |
| `channel-copy-link.png` | 대상 Teams 채널의 **...** 메뉴에서 **Copy link** 선택 |
| `hello-world.png` | Teams 채널에 게시된 **Hello, world!** Adaptive Card 전송 결과 |
| `github-webhook.png` | GitHub `workflow_run` Webhook을 통해 Teams 채널에 전달된 성공 Adaptive Card |
| `azure-portal-entra.png` | Azure Portal에서 **Microsoft Entra ID** 검색 및 선택 |
| `app-registration.png` | `TeamsNotifyApp`의 Microsoft Graph 애플리케이션 권한과 관리자 동의 상태 |
| `automated-cloud-flow.png` | Power Automate의 **Automated cloud flow** 선택 타일 |
| `automated-cloud-flow-skip.png` | **Build an automated cloud flow** 대화 상자의 **Skip** 선택 |
| `flow-name-add-trigger.png` | 흐름 이름 지정 및 **Add a trigger** 선택 |
| `microsoft-teams-webhook-trigger.png` | **Microsoft Teams Webhook** 커넥터 및 Webhook 요청 트리거 선택 |
| `teams-webhook-trigger-anyone.png` | Webhook 트리거의 **Anyone** 설정 및 저장 후 HTTP URL 생성 안내 |
| `add-post-card-action.png` | 트리거 아래에서 **Microsoft Teams**의 카드 게시 작업 추가 |
| `select-team-custom-value.png` | Teams 카드 게시 작업에서 **Enter custom value** 선택 |
| `enter-team-expression.png` | Teams 카드 게시 작업에 동적 Team 식 입력 |
| `teams-action-complete.png` | Teams 카드 게시 작업의 식 및 연결 사용자 최종 확인 |
| `microsoft-365-service-account.svg` | Microsoft 365 관리 센터의 합성 Teams 연결 서비스 계정 |
| `power-automate-flow-designer.png` | Webhook 트리거 및 Teams 동작 |
| `power-automate-teams-action.png` | Teams 동작 구성 |
| `power-automate-flow-history.png` | 활성화된 흐름 및 성공한 실행 |

Team, 채널, 계정, 연결, 환경 및 콜백 URL 값은 제거하거나 합성 값으로
대체했습니다. `create-service-account.png`와 `shared-flow-overview.png`는
첨부된 PNG를 편집하지 않고 그대로 저장했습니다. 자격 증명이나 실제 테넌트
정보가 포함된 원본으로 교체하지 마세요.
