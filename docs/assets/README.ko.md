# 문서 자산

[English](README.md)

문서 이미지는 해당 이미지를 소유하는 사용자용 가이드별로 구성됩니다.

- [`card-previews/`](card-previews/README.ko.md): 쌍으로 구성된 기본 예제의
  Slack 및 Teams 클라이언트 캡처
- [`integrated-scenario/`](integrated-scenario/README.ko.md): GitHub, GitLab,
  Argo CD, AKS, Bookinfo 및 시나리오 증거 자료
- [`power-automate-teams-workflow/`](power-automate-teams-workflow/README.ko.md):
  민감 정보가 제거된 Power Automate 설정 및 실행 기록 캡처
- [`logic-app-teams-delivery/`](logic-app-teams-delivery/README.ko.md): 민감
  정보가 제거된 Logic Apps 워크플로, 보안, Teams 동작 및 실행 기록 캡처

실제 클라이언트 또는 제어 플레인 캡처만 여기에 둘 수 있습니다. 이미지를
유용한 최소 영역으로 자르고, 계정 및 환경 ID를 제거하고, 이미지 메타데이터를
제거한 다음, 커밋하기 전에 URL에 자격 증명이 없는지 확인하세요.
