# Example parameters

Only deployable synthetic parameters belong here. Real subscription, tenant,
resource, connection, and callback values remain private.

Example files document shape and safe defaults. They must not be copied back
from `az deployment`, exported portal templates, Terraform state, or a live
Power Platform environment.

Use command-line overrides or a private parameter store for real deployments,
and inspect generated output before attaching it to an issue or build artifact.
