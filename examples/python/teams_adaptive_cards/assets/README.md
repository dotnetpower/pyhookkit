# Teams Adaptive Card assets

This directory is the publishable HTTPS root used by image-led Teams gallery
and scenario examples.

- [`ATTRIBUTION.md`](ATTRIBUTION.md) records upstream paths, modifications, and
  licenses.
- `samples/` preserves the directory structure referenced by card markers.
- Runtime delivery resolves markers from `EXAMPLE_ASSET_BASE_URL`.

Do not add client screenshots here; they belong under
[`docs/assets/`](../../../../docs/assets/README.md). Do not add unlicensed
images, generated credentials, redirecting URLs, or files larger than the
documented Teams limits.
